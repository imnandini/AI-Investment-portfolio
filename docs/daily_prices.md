# Automatic daily closing prices

The personal app can fetch Yahoo Finance daily closes with `yfinance`. Set `DAILY_PRICE_PROVIDER=yahoo` in the root `.env`, then rebuild/restart the backend. No API key or broker login is required. `none` disables new fetches and retains saved prices.

The portfolio analytics endpoint checks prices when a portfolio opens, after holdings imports, and on refresh. Chat and stock/portfolio briefs use the same refresh path. A backend worker checks saved instruments every five minutes while the backend runs. Successful downloads are cached until the next Indian calendar day; if a weekday close is still missing, the source is rechecked after two hours. Failures retry after 30 minutes. The visible portfolio rechecks analytics every minute without repeatedly downloading an already cached day. Large portfolios are processed in batches; pending updates are labeled. The app cannot update while Docker/the backend is stopped; opening it again fetches recent history.

Only completed daily bars through yesterday in Asia/Kolkata are requested. Weekends, exchange holidays, suspensions and provider delays can leave the latest available close earlier than yesterday. Each holding displays its actual date, source and resolved exchange. Prices more than seven days old remain stale under the existing analytics policy; unknown-dated prices are not relabeled as fresh. No missing price, purchase cost or FX rate is estimated.

Supported coverage is INR/USD equities and ETFs when identity and currency can be verified. Known NSE/BSE symbols use Yahoo's `.NS`/`.BO` tickers. INDmoney internal references and missing exchanges use exact public company-name matches; fuzzy search results are rejected, and an exact NSE match is preferred when the source exchange was not supplied. Yahoo metadata must confirm the currency, equity/ETF type and the resolved Indian exchange. Ambiguous companies remain unpriced with a visible explanation. Mutual-fund NAVs and EPF/PPF balances keep their imported-data workflow.

Daily closes are stored by instrument and trading date, with provider, provider ticker, exchange and retrieval time. A refresh initially retrieves up to 45 calendar days and updates existing dates idempotently; earlier stored dates are retained. A newer automatic close replaces an older manual reference. A newer dated imported/manual price can still supply the latest valuation. The manual form is an optional collapsed fallback.

Previous-session and one-week comparisons require a shared trading date and base-currency close for every current security. The week comparison uses the last shared close on or before seven calendar days before the latest shared date. Both dates and values are shown. Current quantities are applied to both dates: these comparisons measure movement in the currently held basket, not actual historical account performance, realized returns, cash flows, dividends, fees or taxes. Raw close is requested with `auto_adjust=False`; provider split adjustments/corrections may still affect history. Do not interpret a comparison across corporate actions as an independently audited investment return.

`GET /portfolios/{id}/prices/history?days=45` returns stored daily prices for current holdings. It requires the owner's authentication and performs no new market download. Analytics includes `daily_prices` with coverage, pending/provider issues and complete day/week comparisons. Public price history is keyed to the shared instrument, while access to a portfolio and its holdings remains owner-scoped.

Yahoo/yfinance is an unofficial, best-effort personal-use source and can be delayed, incomplete or rate-limited. It is not a commercial market-data agreement. The owner selected this source for the local personal app; use an appropriately licensed provider before offering redistributed data in a shared commercial product. Source behavior and intended use are described in the [yfinance project](https://github.com/ranaroussi/yfinance) and [history API reference](https://ranaroussi.github.io/yfinance/reference/api/yfinance.Ticker.history.html).
